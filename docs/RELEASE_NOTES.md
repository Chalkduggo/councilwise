## Councilwise 1.0.2 — eight models, one verdict

Upload one document and a short brief. Several AI models review it independently, review each other anonymously, a Council Head rules on every dispute, and a moderator writes the final report — with a confidence score you can see inside.

**Downloads**
- `Councilwise-Setup-1.0.2.exe` — installer for Windows 10/11 (recommended)
- `Councilwise-Portable-1.0.2.exe` — runs without installing
- `SHA256SUMS.txt` — checksums

Windows SmartScreen may say the app is from an unknown publisher because it is not code-signed yet. Choose **More info → Run anyway**.

**Tips for the first run**
- Create a separate Gmail account just for Councilwise and use it to sign in to every model — quick, and it keeps your everyday account separate.
- During a council, one Chrome/Edge window opens per model and the prompts are typed in automatically. That's normal; leave the windows open.

**New to Councilwise?** Click **Try the demo** on the Home screen: a full council runs with simulated members, no sign-in needed.
